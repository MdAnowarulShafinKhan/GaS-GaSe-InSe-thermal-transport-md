# Results

`results_summary.csv` is the compact cross-project table. The original Excel workbooks are retained because they are part of the project record, while normalized CSV files are added for easy inspection/versioning.

The strain and vacancy values are fixed-length production results from the working archive. The validation directory contains multiple finite-size selections; do not mix fixed-length conductivity with extrapolated `kappa_inf` in the same comparison without labeling them.
